## 핵심 개념


### 1. 키프레임 관리


#### 왜 키프레임이 필요한가?


**비유:** 여행 사진을 찍을 때, 같은 위치에서 30장 찍으면 앨범만 두꺼워짐. "경치가 바뀔 때마다 1장씩"이 훨씬 효율적.


- **모든 프레임 저장**: 메모리 폭발, 계산량 과다
- **유사한 프레임 중복**: 정보량 낮음 (같은 위치에서 여러 장)
- **키프레임**: "정보가 충분히 다른" 프레임만 선별


**숫자로 보면:**
```
30 FPS 카메라, 10분 주행 = 18,000 프레임
키프레임만 선별하면 = 200-500개 (1-3% 수준)
→ BA 계산량이 수천 배 감소
```


#### 키프레임 선택 기준


| 기준 | 설명 |
|------|------|
| 이동 거리 | 일정 거리 이상 이동 시 |
| 회전 각도 | 일정 각도 이상 회전 시 |
| 매칭 비율 | 기존 키프레임과 공유 특징점 감소 시 |
| 시간 간격 | 최소 시간 보장 |


#### VINS에서의 키프레임


- **Sliding window**: 최근 N개 키프레임 유지 (`WINDOW_SIZE`)
- 오래된 키프레임 → **Marginalization** (정보 요약 후 제거)
- Window 크기 trade-off: 크면 정확하지만 느림, 작으면 빠르지만 정보 손실

### 2. Bundle Adjustment


#### BA란?


카메라 포즈들(T_i)과 3D 점들(X_j)을 **동시에** 최적화하여 재투영 오차를 최소화.


- **Bundle**: 3D 점에서 나온 광선 다발
- **Adjustment**: 광선들이 일관되도록 조정


#### 비용 함수


```
min Sigma_ij ||x_ij - pi(K, T_i, X_j)||^2
```


- `x_ij`: 카메라 i에서 관측된 점 j의 2D 좌표
- `pi()`: 3D → 2D 투영 함수 (K * [R|t] * X)
- `T_i`: 카메라 i의 포즈
- `X_j`: 3D 점 j의 좌표
- **재투영 오차**: 관측된 위치와 예측된 투영 위치의 차이


#### BA 최적화 구조


**자코비안의 희소 구조:**
- 각 관측은 하나의 카메라 + 하나의 3D 점에만 연결
- Hessian 행렬이 블록 대각선 구조


**Schur Complement (핵심!):**
```
Hessian = [H_cc H_cp]
          [H_pc H_pp]


1. 3D 점 변수(p)를 먼저 소거
2. 카메라 포즈(c)만의 작은 시스템 풀기
3. 3D 점은 역대입으로 복구
→ 계산 복잡도 대폭 감소
```


#### Local BA vs Global BA


| 구분 | Local BA | Global BA |
|------|----------|-----------|
| 범위 | 최근 키프레임 + 관련 점 | 전체 맵 |
| 시점 | 매 키프레임 삽입 시 | Loop closure 후 |
| 속도 | 실시간 가능 | 느림 |
| VINS | sliding window 최적화 | 4-DOF 포즈 그래프 |

### 3. SLAM에서 어디에 쓰이나?


- **VINS `optimization()`**: sliding window 내 Local BA + IMU factor
- **Visual factor** = BA의 재투영 오차
- **FeatureManager**: 특징점 생명주기 관리 (키프레임 연결)

## 자체 점검


아래 질문에 **자기 말로** 답을 노트에 써보세요:


1. **"BA가 뭔가요?"** (면접 빈출)
   - 힌트: 재투영 오차, 카메라 포즈 + 3D 점 동시 최적화


2. **"Schur complement가 BA를 빠르게 만드는 원리는?"**
   - 힌트: 3D 점이 카메라보다 훨씬 많음, 먼저 소거


3. **"VINS의 sliding window는 어떤 trade-off가 있나요?"**
   - 힌트: 크면 정확/느림, 작으면 빠름/정보 손실


4. **"키프레임 선택이 너무 빈번하면? 드물면?"**
   - 빈번: 유사 정보 중복, BA 느려짐
   - 드물: 특징점 추적 끊김, 정확도 저하


5. **"Marginalization이란?"**
   - 힌트: sliding window 밖의 오래된 정보를 요약해서 보존
