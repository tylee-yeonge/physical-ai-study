  Frame 3→4: scale = 0.98  (2% 오차)

## 📚 핵심 개념

### 1. Stereo 카메라 - 기하학적 스케일 복구

**원리:**
```
Stereo 카메라는 두 카메라 사이 거리(baseline)를 알고 있음

     좌 카메라        우 카메라
        │←── baseline (b) ──→│
        │                     │
        │    ┌──────────┐    │
        │    │  물체 P   │    │
        │    └──────────┘    │
        │   /              \ │
        │  /    depth (Z)   \│
        │ /                  │

depth = f * b / disparity

여기서:
  f = 초점 거리 (카메라 내부 파라미터, 알고 있음)
  b = baseline (두 카메라 거리, 알고 있음, 예: 12cm)
  disparity = 좌우 이미지에서 같은 점의 x좌표 차이 (측정)
```

**핵심: 스케일 문제가 없음!**
```
baseline b = 0.12m (제조 시 고정)
→ depth의 단위가 자동으로 미터(m)

예시:
  f = 500 pixel
  b = 0.12 m
  disparity = 10 pixel

  depth = 500 * 0.12 / 10 = 6.0 m  ← 절대 스케일!
```

**장점과 한계:**
```
✅ 장점:
  - 스케일 문제 완전 해결
  - 추가 센서 불필요
  - 정적/동적 장면 모두 OK

❌ 한계:
  - 하드웨어 비용 증가 (카메라 2개)
  - 캘리브레이션 필요 (외부 파라미터)
  - 원거리에서 정확도 저하 (disparity → 0)
  - 좁은 baseline → 근거리만 정확
```

### 2. IMU 융합 (VIO의 핵심!)

**이것이 Phase 4의 주제입니다!**

#### 2.1 IMU란?

```
IMU (Inertial Measurement Unit) = 관성 측정 장치

구성:
  - 가속도계 (Accelerometer): 3축 가속도 측정 [ax, ay, az]
  - 자이로스코프 (Gyroscope): 3축 각속도 측정 [wx, wy, wz]

출력:
  - 가속도: a = [ax, ay, az] (m/s²)  → 200~1000 Hz
  - 각속도: w = [wx, wy, wz] (rad/s) → 200~1000 Hz

특징:
  - 매우 빠른 출력 (카메라: 30Hz, IMU: 200Hz+)
  - 자체적으로 위치 추정 가능 (적분)
  - 중력 방향 감지 가능
```

#### 2.2 IMU로 스케일 복구하는 원리

```
가속도를 이중 적분하면 위치를 얻음:

  가속도 a(t)  →  속도 v(t) = ∫ a dt  →  위치 p(t) = ∫ v dt

  [m/s²]        [m/s]                   [m]
    ↑              ↑                      ↑
  IMU 측정     1차 적분                2차 적분

핵심: IMU의 출력 단위는 m/s² (절대 단위!)
→ 적분 결과도 m 단위 (절대 스케일!)
```

**Vision과 IMU의 상호 보완:**
```
┌──────────────┬─────────────────┬─────────────────┐
│              │    Vision       │      IMU        │
├──────────────┼─────────────────┼─────────────────┤
│ 방향(회전)   │ ✅ 정확         │ ⚠️ 드리프트     │
│ 스케일       │ ❌ 모호         │ ✅ 절대 스케일   │
│ 빠른 움직임  │ ❌ 모션 블러    │ ✅ 고속 샘플링   │
│ 느린 움직임  │ ✅ 안정적       │ ❌ 가속도 ≈ 0   │
│ 장시간       │ ✅ 드리프트 적음│ ❌ 드리프트 누적 │
│ 텍스처 없음  │ ❌ 실패         │ ✅ 독립적       │
│ 주파수       │ 30 Hz          │ 200+ Hz         │
└──────────────┴─────────────────┴─────────────────┘

→ 완벽한 상호 보완!
  Vision이 약한 곳에서 IMU가 강하고,
  IMU가 약한 곳에서 Vision이 강함
```

#### 2.3 VIO (Visual-Inertial Odometry)

```
VIO = Vision + IMU 융합

Vision만:  방향 ✅, 스케일 ❌, 고속 ❌
IMU만:     스케일 ✅, 장시간 ❌ (드리프트)
VIO:       방향 ✅, 스케일 ✅, 고속 ✅, 장시간 ✅

대표적인 VIO 시스템:
  - VINS-Mono (Phase 4에서 학습!)
  - OKVIS
  - MSCKF
  - ORB-SLAM3 (IMU 모드)
```

#### 2.4 IMU의 드리프트 문제

```
IMU만으로는 장시간 사용 불가:

가속도 적분의 오차 누적:
  바이어스 b_a = 0.01 m/s²  (작은 오차)

  위치 오차 = 0.5 * b_a * t²

  t = 1초:   오차 = 0.005 m  (5mm, OK)
  t = 10초:  오차 = 0.5 m    (50cm, 문제!)
  t = 60초:  오차 = 18 m     (18m, 심각!)
  t = 300초: 오차 = 450 m    (450m, 사용 불가!)

→ Vision으로 드리프트를 보정해야 함!
→ 이것이 VIO의 핵심 아이디어
```

### 3. 기타 스케일 복구 방법 (참고)

#### 3.1 알려진 물체 크기 이용

```
방법:
  장면에 크기를 아는 물체가 있으면 스케일 결정 가능

예시:
  - 도로 차선 폭: 3.7m (표준)
  - ArUco 마커: 정확한 크기 알고 있음
  - 사람 키: ~1.7m (대략적)

구현:
  이미지에서 물체 크기 = s pixel
  실제 물체 크기 = S meter
  스케일 팩터 = S / (s * depth_normalized)

한계:
  ❌ 항상 알려진 물체가 있어야 함
  ❌ 물체 검출 오류 시 스케일도 틀림
  ❌ 범용성 부족
```

#### 3.2 높이 고정 가정 (지면 평면)

```
방법:
  카메라가 지면에서 일정 높이에 있다고 가정

예시:
  자동차 카메라: 높이 1.2m 고정
  AMR 카메라: 높이 0.5m 고정

구현:
  지면 평면 검출 → 카메라-지면 거리로 스케일 보정

한계:
  ❌ 평평한 지면만 가능
  ❌ 경사로, 계단에서 실패
  ❌ 카메라 높이가 변하면 안 됨
```

#### 3.3 GPS 융합

```
방법:
  GPS로 절대 위치를 얻어 스케일 결정

구현:
  Vision으로 상대 경로 추정 → GPS로 절대 스케일 보정

한계:
  ❌ 실내에서 사용 불가!
  ❌ GPS 정밀도: ~3m (민간), ~0.3m (RTK)
  ❌ 건물 사이, 터널에서 신호 없음
  ❌ 업데이트 주파수 낮음 (1~10 Hz)

사용 사례:
  ✅ 자율주행 차량 (실외)
  ✅ 드론 (실외)
  ❌ AMR (실내) → GPS 사용 불가!
```

## 🤔 왜 IMU인가?

### AMR(자율 이동 로봇) 관점에서

```
AMR에는 이미 IMU가 내장되어 있습니다!

일반적인 AMR 센서 구성:
  ✅ 카메라 (필수)
  ✅ IMU (이미 있음!)    ← 추가 비용 없음!
  ✅ 엔코더 (이미 있음!)
  △ LiDAR (선택, 비쌈)
  ❌ GPS (실내 사용 불가)

IMU가 최적인 이유:
  1. 추가 센서 없이 스케일 복구 가능
  2. 실내/실외 모두 작동
  3. 빠른 움직임에서 Vision 보완
  4. 소형, 저가, 저전력
  5. 이미 대부분의 로봇/모바일에 탑재
```

### 빠른 움직임에서의 장점

```
카메라만 사용 시:
  정상 속도: 🟢 특징점 추적 OK
  빠른 회전: 🔴 모션 블러 → 추적 실패
  빠른 이동: 🔴 특징점 이탈 → VO 실패

IMU 추가 시:
  정상 속도: 🟢 Vision 주도
  빠른 회전: 🟢 IMU가 회전 추정 → Vision 복구 도움
  빠른 이동: 🟢 IMU가 위치 예측 → 특징점 검색 범위 축소

실제 시나리오:
  로봇이 장애물을 피해 급회전
  → 카메라 영상 블러
  → IMU가 회전 추정 유지
  → 블러 해소 후 Vision 복구
  → 연속적인 추적 유지!
```

## ✅ 자체 점검

### Q1. Stereo 카메라에서 depth를 구하는 공식은?

```
depth = f * b / disparity

- f: 초점 거리 (pixel)
- b: baseline (m)
- disparity: 좌우 이미지의 x좌표 차이 (pixel)
```

### Q2. Vision과 IMU가 상호 보완적인 이유는?

```
Vision: 방향 정확, 스케일 모호, 느린 움직임에 강함
IMU:    스케일 제공, 드리프트 있음, 빠른 움직임에 강함

→ Vision이 약한 곳에서 IMU가 강하고, 그 반대도 성립
→ 융합하면 둘 다 극복 가능!
```

### Q3. GPS가 실내 로봇에 적합하지 않은 이유는?

```
1. 실내에서 GPS 신호 수신 불가
2. 수신되더라도 정밀도 매우 낮음 (멀티패스)
3. 업데이트 주파수 낮음 (1~10Hz)
4. AMR은 주로 실내 환경에서 운용
```

### Q4. VIO는 무엇의 약자이며, 핵심 아이디어는?

```
VIO = Visual-Inertial Odometry (시각-관성 주행 거리 측정)

핵심 아이디어:
- Vision(카메라)과 Inertial(IMU) 센서를 융합
- Vision으로 방향/구조 추정
- IMU로 스케일/고속 동작 보정
- 상호 보완적 융합으로 정확한 상태 추정
```

### Q5. IMU만으로 위치 추정 시 문제점은?

```
가속도 적분의 오차가 시간의 제곱에 비례하여 증가:
  위치 오차 ∝ t²

바이어스 0.01 m/s² 기준:
  1초 → 5mm
  10초 → 50cm
  60초 → 18m

→ 장시간 사용 불가, Vision으로 보정 필요!
```

## 🎯 핵심 요약

1. **Stereo 카메라**
   - baseline이 알려져 있어 절대 스케일 복구
   - depth = f * b / disparity
   - 추가 하드웨어 비용 필요

2. **IMU 융합 (VIO)**
   - 가속도 적분으로 절대 스케일 제공
   - Vision과 완벽한 상호 보완
   - AMR에 이미 IMU 탑재 → 추가 비용 없음
   - Phase 4의 핵심 주제!

3. **기타 방법**
   - 알려진 물체: 범용성 부족
   - 높이 고정: 평탄한 환경만 가능
   - GPS: 실내 사용 불가

4. **왜 VIO인가**
   - 추가 센서 없이 스케일 복구
   - 실내/실외 모두 작동
   - 빠른 움직임에서 Vision 보완
   - 업계 표준 (VINS-Mono, ORB-SLAM3)

5. **Phase 3 총정리**
   - 13주간 VO 파이프라인 완전 이해
   - BA 이론과 실습 (g2o + Ceres)
   - 스케일 문제 인식 → IMU 필요성 도출
