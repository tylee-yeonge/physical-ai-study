# eval 실행 계획 — N 결정 + 비용 산정 (실습 2)

> 작성일: 2026-08-30
> 환경: RTX 4070 12GB, dev container venv (.venv-vla), nf4+dq+fp16, eager — `Measurements/openvla-rtx4070-int4/environment.md` 와 동일
> 역할: 확정 N 과 그 근거, zero-shot 재측정 필요 여부, seed 목록 확장 규칙을 실행 전에 고정한다

## 1. 실측 근거

| 항목 | 값 | 출처 |
|---|---|---|
| `predict_action` 추론 | 300.3 ms (std 3.8, p95 +4.5) | `Measurements/openvla-rtx4070-int4` Block 1 실측 (동일 GPU·동일 양자화 설정) |
| overhead (sim step 4회 + 이미지 변환) | 10.5 ms | probe 실측 — 모델 없이 정책 결정 100회 분량을 돌려 총 시간 / 횟수 (random action, 224x224 rgb) |
| 스텝당 합계 | 310.8 ms | 위 두 값의 합 |
| episode 최대 시간 | 15.5 s | 310.8 ms x POLICY_STEPS 50 (조기 종료 없는 최악 기준) |

- episode 시간은 **최악 기준**이다. 성공하면 조기 종료하지만, 성공률이 낮아 대부분 step cap 까지 가므로 최악에 가깝다고 놓는다.
- processor 전처리는 predict_action 수치에 사실상 포함돼 있다 (Block 1: `predict()` 전체 mean 298.8 ms ≈ predict_action 단독).

## 2. 후보 N 비교

반폭은 해상도 비교용 최악 기준(p=0.5, 정규 근사)이다. 실제 보고에 쓸 구간 방법은 `stat_method.md`(실습 3)에서 확정한다.

| N | 95% 반폭 (최악) | 모델당 시간 | 두 모델 합계 |
|---|---|---|---|
| 20 | 21.9%p | 약 5분 | 약 10분 |
| 50 | 13.9%p | 약 13분 | 약 26분 |
| 100 | 9.8%p | 약 26분 | 약 52분 |
| 200 | 6.9%p | 약 52분 | 약 104분 |

## 3. 확정 결정

| 항목 | 값 |
|---|---|
| 스텝당 실측 시간 | 310.8 ms (추론 300.3 + overhead 10.5) |
| episode 최대 시간 | 15.5 s |
| 후보 N 별 총 실행 시간 | §2 표 |
| **확정 N** | **100** |
| 확정 근거 | 반폭 약 10%p 면 두 자릿수 %p 차이를 구분할 해상도가 되고, 두 모델 합계 약 52분으로 한 세션 안에 끝난다. N=200 은 시간이 2배인데 반폭 개선은 9.8 -> 6.9%p 에 그치고, N=50 은 반폭 14%p 라 중간 크기의 개선을 구분하지 못한다 |
| **zero-shot 재측정 필요 여부** | **필요** — week0 은 N=20 (seed 0-19). N=100·같은 seed 목록으로 다시 재야 짝지은 비교가 성립한다. 겹치는 20개 seed 는 week0 재현 검사로 활용한다 (실습 4 확인 포인트) |
| seed 목록 확장 규칙 | `eval_seeds = list(range(100))` |

## 4. seed 확장 규칙의 검사 조건

`list(range(100))` 은 다음 세 조건을 만족하며, 앞의 둘은 하네스가 assert 로 실행 시마다 검사한다.

| 조건 | 상태 |
|---|---|
| week0 목록 (0-19) 을 부분집합으로 포함 | 성립 — 하네스 assert |
| week1 학습 seed (1000-1099, 100개) 와 겹침 없음 | 성립 — 하네스 assert |
| week1 개발용 seed (DUMP_SEED=100 등) 미포함 | 성립 — range(100) 은 0-99 |

### 무행동 하한 seed

zero action 만 200 env step 넣는 probe 를 seed 0-99 전수에 돌린 결과, **seed 8 과 58 이 env step 1 에서 성공**한다 (초기 배치가 성공 조건을 이미 만족하는 degenerate 배치 — `sim_facts.md` 의 "degenerate 는 확률적이며 seed 목록을 바꾸면 다시 나온다" 그대로). week0 이 `noop_seeds=[8]` 로 다룬 것과 같은 부류이며, 목록 확장으로 58 이 추가됐다.

- 두 seed 는 목록에서 빼지 않는다 — 두 모델에 똑같이 적용되므로 짝지은 비교(불일치 쌍)에는 영향이 없고, week0 목록 포함 조건(8 은 week0 소속)도 유지된다.
- week6 집계에서 이 두 seed 의 성공은 조작 성공이 아니므로, week0 방식대로 "placed 중 조작으로 얻은 것" 을 `noop_seeds={8, 58}` 제외로 병기한다.

## 5. 예측 대 실측 대조

N=100 fine-tuned 실행의 결과 파일 타임스탬프 간격이 약 30분으로, 계산(모델당 약 26분 + 모델 적재 수 분)과 부합한다.
