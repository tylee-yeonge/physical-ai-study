> 역할: 구간 추정 방법, 짝지은 비교 방법, 유의 수준, 보고 문장 틀을 결과를 보기 전에 고정한다
> 계산 환경: scipy 1.18.0 (`.venv-vla`). statsmodels 미설치

## 1. 구간 추정: Wilson score interval

### 1.1 후보 비교

| 방법 | 계열 | 0/N 에서 | 폭 | 비고 |
|---|---|---|---|---|
| Wald (정규 근사) | 근사 | 폭 0 — 보고 불가 | 대칭 | 실습 3-1 계산으로 확인한 구조적 결함. 기각 |
| Wilson score | 근사 보정 | 폭 > 0 | 비대칭 | **채택** |
| Clopper-Pearson | 근사 없음 (exact) | 폭 > 0 | 비대칭 | 명목 95% 를 항상 넘는 과잉 보수 — 구간이 필요 이상 넓다 |
| Jeffreys (베이즈) | 근사 없음 | 폭 > 0 | 비대칭 | 성질은 Wilson 과 비슷하나 사전분포 선택을 설명해야 한다 |

### 1.2 채택 근거 (실습 3-1 의 질문에 대한 답)

- **0/N 에서 어떤 값을 주는가**: 0/98 에서 [0%, 3.77%] (실측 계산). 폭이 0 이 되지 않아 "성공 0 이어도 참 성공률의 상한을 말할 수 있다".
- **대칭인가 비대칭인가**: 비대칭. 관측 비율이 경계(0, 1)에 가까울수록 구간이 안쪽으로 치우쳐 [0, 1] 을 벗어나지 않는다.
- **보수적인가**: 명목 95% 에 근접한 실제 포함률 (Brown-Cai-DasGupta 2001 의 권고). Clopper-Pearson 처럼 과잉으로 넓지 않다.
- **계산 비용**: 닫힌 식. N=100 규모에서 무시할 수준.

### 1.3 계산 함수 (확정)

```python
from scipy.stats import binomtest

ci = binomtest(k, n).proportion_ci(confidence_level=0.95, method="wilson")
# ci.low, ci.high
```

## 2. 짝지은 비교: exact McNemar (불일치 쌍 이항검정)

같은 seed 목록을 쓰므로 관측이 짝지어져 있다 (README §4). 2x2 표의 `a`(둘 다 성공), `d`(둘 다 실패)는 정보가 없고, 판정은 불일치 쌍 `b`(zero 만 성공), `c`(fine-tuned 만 성공)로 한다.

### 2.1 검정 방법 (확정)

- 귀무가설 아래 `c ~ Binomial(b + c, 0.5)` 인 **exact 이항검정** (asymptotic McNemar 의 카이제곱 근사를 쓰지 않는다).
- 근거: 불일치 쌍이 몇 건 안 될 가능성이 높다 (zero-shot 성공이 거의 없으면 불일치 쌍 ≈ fine-tuned 단독 성공 수). 카이제곱 근사는 소표본에서 무너지고, exact 검정은 표본 크기에 무관하게 성립한다.

```python
from scipy.stats import binomtest

p = binomtest(c, b + c, 0.5, alternative="two-sided").pvalue
```

### 2.2 단측 vs 양측 (확정: 양측)

- **양측 채택.** "fine-tuning 이 개선한다" 가 기대 방향이지만, 악화 가능성(도메인 갭, 머지·양자화 손실)도 실제로 있다. 단측을 쓰면 악화가 관측돼도 검정이 그것을 볼 수 없고, 결과를 본 뒤 방향을 바꾸고 싶은 유혹이 생긴다 — 그 여지를 지금 없앤다.
- 유의 수준 alpha = 0.05.

### 2.3 표본이 작을 때의 대응 (확정)

exact 이항검정으로 계산한 한 방향 몰빵 기준 최소 불일치 쌍 수:

| 불일치 쌍 (한 방향) | 양측 p |
|---|---|
| 5:0 | 0.0625 — 유의 불가 |
| 6:0 | 0.0312 — 유의 |

- **불일치 쌍 합이 6 미만이면 이 검정으로 유의 판정이 구조적으로 불가능하다.** 이 경우 "차이 없음" 이 아니라 **"판정 불가 (불일치 쌍 {k}건, 검정력 부족)"** 으로 보고한다.
- 불일치 쌍이 0 이면 검정 자체를 하지 않고 "판정 불가 (불일치 쌍 0)" 으로 보고한다.

## 3. 대상 지표와 seed 처리 (확정)

| 항목 | 결정 |
|---|---|
| 1차 지표 | `placed` (성공), **무행동 하한 seed {8, 58} 제외한 98쌍 기준** (`eval_plan.md` 무행동 하한 절) |
| 병기 | 100쌍 전체 기준 성공 수 (구간 없이 원값만) |
| 단계별 (reached/grasped/lifted) | **기술 통계만** — 개수를 병기하고 구간·검정을 붙이지 않는다. 지표 3개에 각각 검정을 걸면 다중 비교가 되고, 이 단계 지표들은 해석 보조가 목적이다 |
| noop seed 와 짝지은 비교 | seed 8, 58 은 두 모델 모두 성공(셀 `a`)이므로 불일치 쌍 판정에는 원래 영향이 없다. 제외는 구간 추정의 분자·분모에만 작용한다 |

## 4. 보고 문장 틀 (숫자만 나중에 채운다)

```
zero-shot   {성공}/98 (95% Wilson 구간 {하한}-{상한}%) [전체 {성공raw}/100]
fine-tuned  {성공}/98 (95% Wilson 구간 {하한}-{상한}%) [전체 {성공raw}/100]
불일치 쌍   개선 c={c}건 / 악화 b={b}건 -> exact McNemar 양측 p={p} -> 판정 {아래 규칙}
단계별      reached {z}/98 -> {f}/98 / grasped {z}/98 -> {f}/98 / lifted {z}/98 -> {f}/98
결론        {짝지은 판정을 1차 근거로, 구간은 크기 서술로만 쓴 한 문장}
```

판정 문구 규칙 (결과가 어느 쪽이든 이 셋 중 하나로만 쓴다):

| 조건 | 판정 문구 |
|---|---|
| b + c >= 1 이고 p < 0.05 | "유의한 {개선/악화} (방향은 b, c 크기로)" |
| b + c >= 1 이고 p >= 0.05 | "판정 불가 — 불일치 쌍 {b+c}건에서 방향을 확정할 수 없음" |
| b + c = 0 | "판정 불가 — 불일치 쌍 0" |

- 구간 겹침 여부는 결론의 근거로 쓰지 않는다 — 겹침은 "차이 없음" 의 증거가 아니고, 짝지은 설계에서는 McNemar 가 판정을 담당한다. 구간은 각 모델 성공률의 불확실성 크기를 전달하는 용도로만 쓴다.
