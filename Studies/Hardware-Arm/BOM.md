## 확정 구성 (단일 구매)

| 항목 | 내용 | 비용 |
|---|---|---|
| 팔 키트 | SO-101 리더 + 팔로워 미조립 키트 (TheRobotStudio + HF 오픈소스 설계). 리더 STS3215 7.4V x6 / 팔로워 STS3215-C018 12V 1:345 30kg·cm x6. 3D 프린팅 부품 포함, 판매자 개별 테스트 후 발송 | 약 55만원 |
| 손목 카메라 | USB 카메라 1대 (스파이크는 보유 ELP Stereo 1대로 시작 가능) | 1-3만원 |
| 작업대 자재 | 클램프, 테이블 고정, 작업 영역 매트 (스파이크는 임시 고정으로 충분) | 소액 |
| 예비 부품 | 서보 1개 여유 (선택 — 첫 조립 파손 대비) | 선택 |

**합계: 약 56-58만원** (국내 판매자, 리드타임 3일)

## 구매 전 확인 — 판매 페이지로 해소 (2026-08-31 판정, 문의 불필요)

| # | 항목 | 판정 |
|---|---|---|
| ① | 리더암 기어비 | 리더 6개 전부 19kg/7.4V **1:147 단일** — 공식 혼합 (C046×3+C044×2+C001×1) 아님. 리더 그리퍼 조작감만 차이, 캘리브·데이터 수집 무영향 (기존 판단 유지, 감수) |
| ② | 전원 어댑터 | **동봉** — 리더 5V 4A ×1 / 팔로워 12V 2A ×1 (국내 생산) |
| ③ | USB-시리얼 보드 | **동봉** — 모터 드라이버 모듈 (버스 서보 어댑터, USB-C) ×2 + USB to C 케이블 ×2 |
| ④ | 손목 카메라 마운트 | 기본 3D 부품에 **없음** — Wrist/Belly/Top 카메라·마운트는 **옵션 별매** → 발주 시 Wrist 옵션 추가. 기본 포함은 정면 '카메라 거치 모듈' 1개 (삼각대 불요 — 보유 ELP 장착 가능 여부는 수령 후 확인) |

기본 구성 (판매 페이지 01-11): 리더 모터×6 / 팔로워 모터×6 / 드라이버 모듈×2 / 어댑터 2종 / USB-C 케이블×2 / 십자 드라이버 / 볼트·너트 세트 / 정면 카메라 거치 모듈 / 리더·팔로워 3D 프린팅 부품

## Stage 2 추가 BOM

**미정** — SO-101 이 이미 6DOF 이므로 과제는 관절 수가 아니라 페이로드·강성이다. 상위 팔 도입 / 소프트웨어 스택 심화 / 양팔 확장 중 선택과 비용 산정은 **2026.11 분기 재평가 안건** (Roadmap/Hardware-Arm.md Stage 2 절). 결정 전에 BOM 을 쓰지 않는다.
