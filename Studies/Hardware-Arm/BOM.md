## 확정 구성 (단일 구매)

| 항목 | 내용 | 비용 |
|---|---|---|
| 팔 키트 | SO-101 리더 + 팔로워 미조립 키트 (TheRobotStudio + HF 오픈소스 설계). 리더 STS3215 7.4V x6 / 팔로워 STS3215-C018 12V 1:345 30kg·cm x6. 3D 프린팅 부품 포함, 판매자 개별 테스트 후 발송 | 약 55만원 |
| 손목 카메라 | USB 카메라 1대 (스파이크는 보유 ELP Stereo 1대로 시작 가능) | 1-3만원 |
| 작업대 자재 | 클램프, 테이블 고정, 작업 영역 매트 (스파이크는 임시 고정으로 충분) | 소액 |
| 예비 부품 | 서보 1개 여유 (선택 — 첫 조립 파손 대비) | 선택 |

**합계: 약 56-58만원** (국내 판매자, 리드타임 3일)

## 구매 전 판매자 확인 (Hardware-Arm.md 확인 항목 표 참조)

- 리더암 기어비 구성 (판매 페이지 C046 단일 vs 공식 혼합 — 조작감 차이, 캘리브레이션 영향 없음)
- 전원 어댑터 동봉 여부 (팔로워 12V / 리더는 키트 사양서 기준)
- USB-시리얼 보드 리더·팔로워 각 1개 동봉 여부 (포트 2개 필요)
- 3D 부품에 손목 카메라 마운트 포함 여부

## 구매 직후 확인

- [ ] 키트 사양서에서 **모터 ID 사전 할당 여부** 확인 (미할당이면 조립 전 모터별 ID 세팅 선행)
- [ ] **펌웨어 버전** 확인

## Stage 2 추가 BOM

**미정** — SO-101 이 이미 6DOF 이므로 과제는 관절 수가 아니라 페이로드·강성이다. 상위 팔 도입 / 소프트웨어 스택 심화 / 양팔 확장 중 선택과 비용 산정은 **2026.11 분기 재평가 안건** (Roadmap/Hardware-Arm.md Stage 2 절). 결정 전에 BOM 을 쓰지 않는다.
