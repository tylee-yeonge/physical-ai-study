## 키트 사양 (판매 페이지 + 수령·조립 확인)

| # | 항목 | 내용 |
|---|---|---|
| ① | 리더암 기어비 | 판매 페이지 기준 리더 6개 전부 19kg/7.4V **1:147 단일** — 공식 혼합 (C046×3+C044×2+C001×1) 아님. 리더 관절별 조작감만 다르고 캘리브·데이터 수집에는 영향이 없어 감수한다. 실물 스티커와 대조한 기록은 없다 |
| ② | 전원 어댑터 | 동봉 — 리더 5V 4A ×1 / 팔로워 12V 2A ×1 (국내 생산). 12V 2A 는 하한이다 — 다관절 고부하에서 서보 리셋 (LED 점멸, `Failed to sync read`) 이 보이면 5A 급으로 교체 (조립 가이드 §0) |
| ③ | USB-시리얼 보드 | 동봉 — 모터 드라이버 모듈 (버스 서보 어댑터, USB-C) ×2 + USB to C 케이블 ×2 |
| ④ | 카메라 마운트 | 기본 3D 부품에는 정면 '카메라 거치 모듈' 1개만 있고, 손목 마운트는 Wrist 옵션에 들어 있다. 보유 ELP 는 거치 모듈에 안 붙는다 (1/4 나사 체결부 불일치 — RESULT §4 #5) |
| ⑤ | 모터 ID | 출하 시 12개 전부 ID 1 (사전 할당 없음) → 조립 전 `lerobot-setup-motors` 로 팔로워·리더 각 1-6 설정 |
| ⑥ | 펌웨어 | 버전을 따로 확인하지 않았다 — setup-motors·캘리브·teleop 정상 동작으로 갈음 |

## 남은 구매 (Stage 1)

없다. 배송 중인 전체 뷰 카메라 + 고정수단의 수령만 남았다.

## Stage 2 추가 BOM

**미정** — SO-101 이 이미 6DOF 이므로 과제는 관절 수가 아니라 페이로드·강성이다. 상위 팔 도입 / 소프트웨어 스택 심화 / 양팔 확장 중 선택과 비용 산정은 **2026.11 분기 재평가 안건** (Roadmap/Hardware-Arm.md Stage 2 절). 결정 전에 BOM 을 쓰지 않는다.

## 비채택 (기록)

Koch v1.1 (Dynamixel, 49-60만원) / 커스텀 XL330+XM430 (BOM 150-225만원) / AR4 — 사유는 [Roadmap/Hardware-Arm.md](../../Roadmap/Hardware-Arm.md) 비채택 기록.

물리 e-stop 용 전원 차단 스위치 — 구매하지 않는다 (2026-09-21 결정). DC 를 끊으면 토크가 풀려 팔이 낙하하므로 (조립 가이드 §7), Stage 1 의 정지 수단은 토크를 유지한 채 현 위치에서 멈추는 소프트웨어 정지로 둔다.
