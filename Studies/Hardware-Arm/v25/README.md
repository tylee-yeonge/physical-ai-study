## 1. N 역산 — "N≥20" 이 아니라 해상도부터

v1.5 방식: 목표 해상도를 먼저 정하고 N 을 역산한다. Wilson 95% 구간 반폭 (최악 p̂=0.5 기준):

| N | 반폭 | 실기 소요 (에피소드 2-3분 가정, 두 모델) |
|---|---|---|
| 20 | ±21%p | ~2h — **신호 해상도 부족** |
| 30 | ±18%p | ~3h |
| 50 | ±14%p | ~5h |
| 80 | ±11%p | ~8h |

- 실기 에피소드 소요 (리셋 포함) 는 **스파이크 must 2 에서 실측**된다 — 그 값으로 위 표를 다시 계산해 "예산 안에서 가장 큰 N" 을 고른다. 권장 출발점: N=50 (짝지은 비교 50쌍).
- 짝지은 비교 (같은 초기 배치에서 두 모델) 를 유지해야 McNemar 가 성립한다 — 배치 i 에서 zero-shot·fine-tuned 를 연달아 (또는 세션 교차로) 돌린다.

## 2. 실기 측정 설계 — sim 과 다른 세 가지

| sim 에서 | 실기에서 | 대응 |
|---|---|---|
| seed 로 초기 배치 재현 | 사람 손 배치 — 비재현 | **배치 마커**: 작업면에 종이 템플릿 (물체 시작 칸 N개 + 목표 칸) 을 붙이고, 배치 번호를 에피소드 메타에 기록. 같은 번호 = 같은 배치로 짝 지음 |
| 무행동 하한 probe (zero action) | 동일하게 가능 | 각 배치에서 zero-action 1회 — 배치 자체로 성공 판정되는 degenerate 배치를 제외 목록에 |
| 실행 순서 무관 (환경 독립) | 조명·배터리·마모가 시간에 따라 흐름 | **세션 교차 (ABBA)**: zero-shot/fine-tuned 를 블록 교차로 배치해 세션 효과가 한 모델에 몰리지 않게 |

- 성공 판정: 환경 info 가 없으므로 **판정 규칙을 문서로 사전 고정** (예: 물체가 목표 칸 경계 안에 정지 = placed). 부분 도달률 (reached/grasped/lifted/placed) 판정 기준도 cm 단위로 미리.
- 통계 방법: v1.5 의 `stat_method.md` (Wilson + exact McNemar, 양측 α=0.05) **그대로 재사용, 결과 전 고정.**

## 3. 하네스 검증 (실기판 상한 대조)

성공률 측정 전에, **사람 teleop 을 같은 판정 규칙에 넣어** 상한을 확인한다 (목표 ≥ 9/10). 사람이 못 하면 판정 규칙이나 task 정의가 잘못된 것 — v1.5 의 "장치 먼저 검증" 논리의 실기 번역이다.

## 4. 완료 기준

> "동일 조건 N쌍 (N 은 해상도 역산 값) 으로 zero-shot vs fine-tuned 를 측정하고, 성공률+부분 도달률+구간을 보고했다. 결과가 어느 쪽이어도 배제/잔여 분석으로 성립한다 (v1.5 와 동일 기준). 문서 상한 준수."
