## 🌟 시작하기 전에

### Week 4 복습: EKF의 문제

```
EKF의 회전 표현 문제:

1. 쿼터니언 q = [w, x, y, z] → 4개 파라미터로 3자유도 표현
   → Over-parameterization!
   → 업데이트 후 |q| ≠ 1 → 정규화 필요

2. 큰 상태에서 직접 선형화 → 오차 큼
   → 회전이 크면 sin/cos 선형 근사 부정확

3. 해결: "큰 값은 그대로 적분, 작은 오차만 칼만 필터로"
```

### 비유: 항해사와 보조 항해사

```
기존 EKF (항해사 혼자):
  "현재 위치는 서울에서 동쪽 127.5km!" (큰 값 전체를 추정)
  → 계산 복잡, 오차 커지기 쉬움

ESKF (항해사 + 보조):
  항해사 (Nominal): "나침반과 속력계로 계속 항해!" (IMU 적분)
  보조 (Error):     "항해사 오차가 +0.3km인 것 같아요" (칼만 필터)

  실제 위치 = 항해사 추정 + 보조의 오차 보정

  장점:
  - 보조는 작은 숫자(오차)만 다룸 → 선형 근사 정확
  - 항해사는 비선형 적분 자유롭게 수행
  - 둘을 합치면 정확한 추정!
```

## 📚 핵심 개념 자세히 알아보기

### 1. ESKF의 핵심 구조

```
┌──────────────────────────────────────────┐
│              ESKF 구조                    │
│                                          │
│   Full State = Nominal State ⊕ Error     │
│                                          │
│   ┌─────────────┐   ┌──────────────┐    │
│   │  Nominal    │   │  Error State │    │
│   │  (큰 값)    │   │  (작은 오차)  │    │
│   │             │   │              │    │
│   │  IMU 적분   │   │  칼만 필터    │    │
│   │  (비선형)   │   │  (선형 OK!)  │    │
│   └──────┬──────┘   └──────┬───────┘    │
│          │                 │            │
│          └────── ⊕ ────────┘            │
│                 │                        │
│           최종 추정값                     │
└──────────────────────────────────────────┘
```

---

### 2. 상태 분해

```
Full State x:
  x = [p, v, q, b_a, b_g]  (위치, 속도, 회전, 바이어스)

Nominal State x̄ (IMU로 적분):
  x̄ = [p̄, v̄, q̄, b̄_a, b̄_g]

Error State δx (작은 오차):
  δx = [δp, δv, δθ, δb_a, δb_g]  ← 15차원

관계:
  p = p̄ + δp        (위치: 단순 덧셈)
  v = v̄ + δv        (속도: 단순 덧셈)
  q = q̄ ⊗ δq(δθ)   (회전: 쿼터니언 곱!)
  b_a = b̄_a + δb_a  (바이어스: 덧셈)
  b_g = b̄_g + δb_g

핵심: 회전 오차 δθ는 3차원 벡터!
  δq ≈ [1, δθ/2]  (작은 각도 근사)
  → 3자유도로 3자유도 표현 (Over-parameterization 해결!)
```

---

### 3. ESKF 알고리즘 (3단계)

```
┌─────────────────────────────────────────────┐
│  Stage 1: Nominal 예측 (IMU 적분)            │
│  ─────────────────────────────────           │
│  IMU 데이터가 올 때마다 (200Hz):             │
│                                             │
│    p̄ += v̄·dt + 0.5·R(q̄)·(a-b̄_a)·dt²      │
│    v̄ += (R(q̄)·(a-b̄_a) + g)·dt             │
│    q̄ *= δq((ω-b̄_g)·dt)                     │
│    b̄_a, b̄_g 유지                            │
│                                             │
│  → 비선형 적분! 자코비안 불필요!              │
├─────────────────────────────────────────────┤
│  Stage 2: Error 예측 (공분산 전파)           │
│  ─────────────────────────────────           │
│                                             │
│    δx는 항상 0 근처 (Reset 후)              │
│    P = F_δ · P · F_δᵀ + Q                  │
│                                             │
│    F_δ: Error State 자코비안 (15×15)         │
│    → δx ≈ 0 근처에서 계산 → 매우 정확!      │
├─────────────────────────────────────────────┤
│  Stage 3: Error 업데이트 + Reset             │
│  ─────────────────────────────────           │
│  측정(Vision)이 올 때 (20Hz):               │
│                                             │
│    K = P·Hᵀ·(H·P·Hᵀ+R)⁻¹                  │
│    δx = K·(z - h(x̄))                       │
│    P = (I - K·H)·P                         │
│                                             │
│  Reset (오차를 Nominal에 반영):              │
│    p̄ += δp                                 │
│    v̄ += δv                                 │
│    q̄ *= δq(δθ)                             │
│    b̄_a += δb_a                             │
│    b̄_g += δb_g                             │
│    δx ← 0  (오차 초기화!)                   │
└─────────────────────────────────────────────┘
```

### 4. 왜 ESKF가 더 좋은가?

```
이유 1: 선형화가 더 정확
  ────────────────────
  EKF: 큰 상태(θ=1.5rad 등)에서 선형화
    → sin(1.5) ≈ 1.5? 아니요! (0.997)

  ESKF: 작은 오차(δθ≈0.01rad)에서 선형화
    → sin(0.01) ≈ 0.01? 네! (0.00999...)
    → 작은 각도 근사가 매우 정확!

이유 2: Over-parameterization 해결
  ─────────────────────────────
  EKF: 쿼터니언 q (4D) → 3자유도
    → 제약: |q|=1, 업데이트 후 정규화
    → 공분산 4×4인데 실제 자유도 3

  ESKF: δθ (3D) → 3자유도
    → 제약 없음! 벡터 덧셈
    → 공분산 3×3 → 정확히 맞음

이유 3: Nominal이 좋은 초기값 제공
  ─────────────────────────────
  IMU 적분이 대략적 추정 → 오차가 작음
  → 선형화 범위 내에서 동작
```

---

### 5. Error State 자코비안 F_δ

```
Error State 전파 (연속시간):
  δṗ = δv
  δv̇ = -R·[a-b_a]× · δθ - R·δb_a + ...
  δθ̇ = -[ω-b_g]× · δθ - δb_g + ...
  δḃ_a = noise
  δḃ_g = noise

여기서 [v]× = 반대칭 행렬 (cross product matrix)
  [v]× = [ 0   -v₃   v₂]
         [ v₃   0   -v₁]
         [-v₂   v₁   0 ]

이산화 (1차 근사):
  F_δ = I + F_c · dt

핵심: δx ≈ 0 근처에서 계산하므로
  sin(δθ) ≈ δθ, cos(δθ) ≈ 1
  → 자코비안이 매우 정확!
```

## 💡 꼭 이해해야 할 핵심 개념

### Reset의 중요성

```
업데이트 후 왜 Reset?

1. 오차(δx)를 Nominal에 반영
2. δx를 0으로 초기화
3. → 다음 스텝에서 δx ≈ 0 보장
4. → 선형 근사가 항상 정확!

Reset 없으면?
  → δx가 커질 수 있음
  → 선형 근사 부정확
  → EKF와 같은 문제 발생
```

### ESKF vs EKF 수치 비교

```
회전 45도 (0.785 rad) 상황:

EKF: sin(0.785) ≈ 0.785? → 실제 0.707 → 오차 11%!
ESKF: sin(0.001) ≈ 0.001? → 실제 0.00099... → 오차 0.01%!

→ 1000배 정확한 선형 근사!
→ 이것이 ESKF의 핵심 장점
```

## 🔍 자체 점검 - 이해했는지 확인!

### Q1: Nominal vs Error
**Q:** Nominal State와 Error State의 역할 차이는?

**A:** Nominal은 IMU로 비선형 적분하는 "대략적 추정"이고, Error는 칼만 필터로 추정하는 "Nominal의 오차"입니다. 최종 추정 = Nominal + Error.

### Q2: Over-parameterization
**Q:** 쿼터니언(4D)에서 δθ(3D)로 바꾸면 뭐가 좋아지나요?

**A:** (1) 3자유도를 3파라미터로 정확히 표현, (2) |q|=1 제약 불필요, (3) 공분산 3×3로 정확한 불확실성 표현. EKF에서는 공분산이 4×4인데 rank 3이라 문제 발생.

### Q3: Reset
**Q:** ESKF에서 Reset을 안 하면 어떻게 되나요?

**A:** δx가 점점 커져서 "작은 오차" 가정이 깨집니다. sin(δθ) ≈ δθ 근사가 부정확해지고, 결국 EKF와 같은 선형화 오차 문제가 발생합니다.

### Q4: 실무 적용
**Q:** ESKF가 쓰이는 실제 시스템은?

**A:** MSCKF (NASA JPL, Mars Rover), Apple ARKit, Google ARCore, DJI 드론 등 대부분의 상용 VIO 시스템이 ESKF 또는 유사 구조를 사용합니다.
