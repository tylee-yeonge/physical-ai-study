## 🌟 시작하기 전에

### 카메라의 한계를 느껴보자

**비유: 눈만으로 걷기 vs 눈+균형감각**
```
상황: 어두운 방에서 걷기

카메라만 (Vision Only):
  - 밝을 때: 잘 보임 ✅
  - 어두울 때: 아무것도 안 보임 ❌
  - 빠르게 회전: 모션 블러 ❌
  - 프레임 사이: 정보 없음 ❌

카메라 + IMU (VIO):
  - 어두울 때: IMU가 모션 추적 ✅
  - 빠른 회전: IMU가 각속도 제공 ✅
  - 프레임 사이: IMU가 보간 ✅
  - 스케일: IMU로 실제 크기 복원 ✅
```

### IMU란 무엇인가?

**IMU (Inertial Measurement Unit)** = 관성 측정 장치

우리 몸의 **전정기관(내이)**과 같은 역할을 합니다.
- 가속도계: 선형 가속도 감지 (엘리베이터 타면 느끼는 힘)
- 자이로스코프: 회전 감지 (머리를 돌릴 때 느끼는 감각)

```
IMU 센서 구성:
┌─────────────────────────────────┐
│         IMU 칩                   │
│  ┌──────────┐  ┌──────────┐     │
│  │가속도계   │  │자이로스코프│     │
│  │(Accel)   │  │(Gyro)    │     │
│  │ ax,ay,az │  │ ωx,ωy,ωz │     │
│  └──────────┘  └──────────┘     │
│  3축 선형가속도  3축 각속도       │
└─────────────────────────────────┘
```

## 📚 핵심 개념 자세히 알아보기

### 1. 가속도계 (Accelerometer)

**원리**: 스프링에 매달린 질량의 변위를 측정

```
정지 상태:                이동 중:
 ┌────┐                   ┌────┐
 │    │                   │    │
 │  ●─┤ ← 중력만          │ ●──┤ ← 중력 + 가속도
 │    │    (9.8 m/s²)     │    │
 └────┘                   └────┘
```

**측정 모델:**
```
a_meas = a_true + g + noise + bias

여기서:
  a_meas  : 센서가 출력하는 값 (우리가 읽는 값)
  a_true  : 실제 선형 가속도 (우리가 원하는 값)
  g       : 중력 가속도 (~9.81 m/s², 항상 포함!)
  noise   : 백색 잡음 (랜덤, 고주파)
  bias    : 바이어스 (느리게 변하는 오프셋)
```

**중요한 포인트:**
| 상태 | 센서 출력 | 실제 가속도 |
|------|----------|-----------|
| 정지 (테이블 위) | ~9.81 m/s² (위 방향) | 0 m/s² |
| 자유 낙하 | ~0 m/s² | 9.81 m/s² (아래) |
| 엘리베이터 올라갈 때 | > 9.81 m/s² | a > 0 |

> 💡 **핵심**: 가속도계는 중력을 "가속도"로 인식합니다!
> 정지 상태에서도 ~9.8 m/s²를 출력합니다.

### 2. 자이로스코프 (Gyroscope)

**원리**: 코리올리 효과를 이용한 각속도 측정

```
회전하지 않을 때:         회전할 때:
    ↑ ω = 0                 ↻ ω ≠ 0
    │                       │
 ───●───                 ───●───
    │                       │
    │                     변위 발생
```

**측정 모델:**
```
ω_meas = ω_true + noise + bias

여기서:
  ω_meas  : 센서 출력 (rad/s)
  ω_true  : 실제 각속도
  noise   : 백색 잡음
  bias    : 바이어스 (시간에 따라 drift)
```

**자이로 바이어스의 무서움:**
```
바이어스 = 0.01 rad/s (작아 보이지만...)

1초 후: 0.01 rad = 0.57°
10초 후: 0.1 rad = 5.7°
100초 후: 1.0 rad = 57.3°   ← 방향이 완전히 틀어짐!

→ 적분 오차가 시간에 비례하여 누적
→ 바이어스 추정이 필수!
```

### 3. IMU 데이터 특성

```
주파수 비교:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
IMU:    ████████████████████████████ 200-1000 Hz
Vision: ■         ■         ■        20-30 Hz
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
        ← 시간 →

IMU는 Vision보다 10-50배 빠르게 데이터를 제공!
```

| 특성 | IMU | Vision |
|------|-----|--------|
| 주파수 | 100-1000 Hz | 20-30 Hz |
| 단기 정확도 | 매우 높음 (ms) | 보통 |
| 장기 정확도 | 낮음 (drift) | 높음 |
| 조명 영향 | 없음 | 큼 |
| 빠른 움직임 | 정확 | 블러 발생 |
| 스케일 | 절대 스케일 | 상대 스케일만 |
| 텍스처 필요 | 없음 | 필요 |

### 4. SLAM에서의 역할

```
Vision과 IMU의 상호 보완:

시간 ────────────────────────────────────→

Vision: ■                    ■                    ■
        KF_i                 KF_j                 KF_k

IMU:    ████████████████████████████████████████████
        │←  이 구간을 IMU가 채움  →│

Vision 없는 구간:
  - IMU가 포즈 예측 (고주파)
  - 빠른 움직임 추적
  - 중력 방향 감지

Vision 있는 구간:
  - IMU drift 보정
  - 스케일 복구
  - 전역 일관성 유지
```

**VIO (Visual-Inertial Odometry)의 장점:**
```
1. 스케일 복구
   Mono Vision: "1m 앞인지 10m 앞인지 모름"
   + IMU:       "가속도로 실제 거리 계산 가능!"

2. 빠른 모션 대응
   Vision: 30Hz → 33ms 갭
   IMU:    200Hz → 5ms 갭
   → 빠른 회전도 추적 가능

3. 초기화 지원
   Vision: 충분한 시차(parallax) 필요
   IMU:    즉시 모션 추정 가능

4. 강건성 향상
   Vision 실패 시 (어둠, 블러):
   → IMU가 단기적으로 모션 유지
```

## 💡 꼭 이해해야 할 핵심 개념

### 측정 모델 심화

**가속도계 측정 모델 (Body frame):**
```cpp
// 가속도계가 측정하는 값
// a_meas = R_wb^T * (a_world - g_world) + b_a + n_a
//
// R_wb: World → Body 회전 행렬
// a_world: 월드 좌표계에서의 선형 가속도
// g_world: 중력 벡터 [0, 0, -9.81]^T
// b_a: 가속도계 바이어스 (느리게 변함)
// n_a: 가속도계 백색 잡음

Eigen::Vector3d a_meas = R_wb.transpose() * (a_world - g_world) + b_a + n_a;
```

**자이로스코프 측정 모델:**
```cpp
// ω_meas = ω_true + b_g + n_g
//
// ω_true: 실제 각속도 (rad/s)
// b_g: 자이로 바이어스
// n_g: 자이로 백색 잡음

Eigen::Vector3d omega_meas = omega_true + b_g + n_g;
```

### 좌표계 이해

```
World Frame (W):            Body Frame (B):
    z ↑                         z ↑ (위)
      │                           │
      │                     x ←───● (앞)
      ●───→ x                     │
     /                           ↓ y (오른쪽)
    y

중력: g = [0, 0, -9.81]^T (World frame)

Body frame에서 느끼는 중력:
  g_body = R_wb^T * g_world

정지 시: a_meas = -g_body = R_wb^T * [0, 0, 9.81]^T
```

### IMU 적분의 문제

```
위치를 구하려면 가속도를 2번 적분해야 합니다:

가속도 → (1차 적분) → 속도 → (2차 적분) → 위치

문제: 노이즈도 함께 적분됨!

가속도 노이즈 σ_a:
  속도 오차: σ_a * √t     (시간의 제곱근에 비례)
  위치 오차: σ_a * t^(3/2) (시간의 1.5승에 비례!)

예시 (σ_a = 0.01 m/s²):
  t=1초:  위치 오차 ≈ 0.01 m
  t=10초: 위치 오차 ≈ 0.32 m
  t=60초: 위치 오차 ≈ 4.6 m  ← 걷기도 전에 발산!

→ IMU만으로는 장기 추적 불가능
→ Vision으로 주기적 보정 필수!
```

## 🔍 자체 점검 - 이해했는지 확인!

### Q1: 가속도계의 정지 출력
**Q:** 가속도계가 테이블 위에 정지해 있을 때 왜 0이 아닌 값을 출력하나요?

**A:**
```
가속도계는 중력도 "가속도"로 측정합니다.
a_meas = a_true + g = 0 + 9.81 = 9.81 m/s² (위 방향)

아인슈타인의 등가 원리:
"중력과 가속도는 구별할 수 없다"
→ 정지 상태에서도 중력을 감지하여 ~9.81 출력
```

### Q2: 자이로 바이어스의 영향
**Q:** 자이로 바이어스가 0.005 rad/s일 때, 1분 후 회전 오차는?

**A:**
```
각도 오차 = bias × 시간
         = 0.005 × 60 = 0.3 rad = 17.2°

→ 1분 만에 17도나 틀어집니다!
→ 바이어스 추정/보정이 VIO의 핵심입니다.
```

### Q3: IMU 주파수
**Q:** IMU 데이터 주파수가 Vision보다 높아야 하는 이유는?

**A:**
```
1. 빠른 모션 추적: Vision 프레임 사이에서 모션 예측
2. 적분 정확도: 높은 주파수 → 적분 오차 감소
3. 실시간성: 카메라 처리 시간(~30ms) 동안 IMU로 보간
4. 진동/충격: 고주파 진동 감지에 필수
```

### Q4: 스케일 복구
**Q:** IMU가 모노 카메라의 스케일 문제를 어떻게 해결하나요?

**A:**
```
모노 카메라: "상대적 움직임만 알 수 있음"
  → "1 unit 이동" (실제 1m? 10m?)

IMU: "절대 가속도 측정 가능"
  → 가속도 × Δt = 속도
  → 속도 × Δt = 거리 (실제 미터 단위)

Vision 궤적 × IMU 스케일 → 실제 크기 궤적!
```

4. **Vision과 상호 보완**

5. **VIO = Visual + Inertial의 최적 융합**
   - 각 센서의 약점을 다른 센서가 보완
