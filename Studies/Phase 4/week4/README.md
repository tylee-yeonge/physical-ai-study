### Week 3 복습: 칼만 필터의 한계

```
칼만 필터의 가정: 시스템이 선형!
  x_k = F · x_{k-1} + w   ← 상태 전이가 행렬 곱

하지만 현실은?
  - IMU 적분: 회전 × 가속도 → 비선형!
  - 회전 표현: 쿼터니언 곱셈 → 비선형!
  - 카메라 투영: 3D→2D → 나눗셈 → 비선형!

  x_k = f(x_{k-1}) + w   ← f가 비선형 함수
  z_k = h(x_k) + v       ← h가 비선형 함수
```

### 비유: 곡선 도로에서의 내비게이션

```
직선 도로 (선형):
  ───────────────→
  "100m 후 도착" → 정확!

곡선 도로 (비선형):
      ╭──╮
  ───╯    ╰───→
  "직선으로 100m" → 틀림!
  "현재 방향으로 조금씩" → 근사적으로 맞음!

EKF = "현재 위치에서 접선 방향으로 선형 근사"
```

## 📚 핵심 개념 자세히 알아보기

### 1. EKF의 핵심 아이디어: 선형화

```
비선형 함수 f(x)를 현재 추정값 x̂ 주변에서 1차 테일러 전개

f(x) ≈ f(x̂) + F · (x - x̂)

여기서 F = ∂f/∂x |_{x=x̂}  ← 자코비안 행렬!

시각화:
  y
  │      ╱ 실제 곡선 f(x)
  │    ╱╱
  │  ╱╱    ╱ 접선 (선형 근사)
  │╱╱   ╱
  ┼──╱──────→ x
       x̂
       ↑
  이 점에서 선형화
```

**핵심**: 현재 추정값 근처에서는 선형 근사가 꽤 정확!

---

### 2. EKF vs 칼만 필터 비교

| 단계 | 칼만 필터 (KF) | EKF |
|------|-------------|-----|
| **상태 예측** | x̂⁻ = **F** · x̂ | x̂⁻ = **f**(x̂) |
| **공분산 예측** | P⁻ = F·P·Fᵀ + Q | P⁻ = **F**·P·**F**ᵀ + Q |
| **잔차** | y = z - **H** · x̂⁻ | y = z - **h**(x̂⁻) |
| **칼만 게인** | K = P⁻·Hᵀ·(H·P⁻·Hᵀ+R)⁻¹ | K = P⁻·**H**ᵀ·(**H**·P⁻·**H**ᵀ+R)⁻¹ |
| **상태 업데이트** | x̂ = x̂⁻ + K·y | x̂ = x̂⁻ + K·y |
| **공분산 업데이트** | P = (I-K·H)·P⁻ | P = (I-K·**H**)·P⁻ |

```
차이점:
  KF:  F, H = 상수 행렬
  EKF: F, H = 자코비안 (매 스텝 재계산!)

  F = ∂f/∂x |_{x̂}    ← 상태 전이 자코비안
  H = ∂h/∂x |_{x̂⁻}   ← 측정 자코비안
```

---

### 3. 자코비안 행렬

```
자코비안 = 다변수 함수의 미분 (행렬 형태)

1변수: f'(x) = df/dx  (스칼라)

다변수:
  f: R^n → R^m 이면

  F = ∂f/∂x = ┌ ∂f₁/∂x₁  ∂f₁/∂x₂  ...  ∂f₁/∂xₙ ┐
               │ ∂f₂/∂x₁  ∂f₂/∂x₂  ...  ∂f₂/∂xₙ │
               └ ∂fₘ/∂x₁  ∂fₘ/∂x₂  ...  ∂fₘ/∂xₙ ┘

  → m×n 행렬
```

#### 예제: IMU 위치 적분의 자코비안

```
상태: x = [p, v, θ]  (위치, 속도, 각도) - 2D 단순화

상태 전이 (비선형):
  p_new = p + v·dt + 0.5·R(θ)·a·dt²
  v_new = v + R(θ)·a·dt
  θ_new = θ + ω·dt

여기서 R(θ) = [cos θ  -sin θ]  ← 비선형!
              [sin θ   cos θ]

자코비안 F = ∂f/∂x:
  ∂p_new/∂p = I          (항등)
  ∂p_new/∂v = I·dt       (선형)
  ∂p_new/∂θ = 0.5·dR/dθ·a·dt²  ← 비선형 부분!

  dR/dθ = [-sin θ  -cos θ]
           [ cos θ  -sin θ]
```

### 4. EKF 전체 알고리즘

```
┌────────────────────────────────────────┐
│            EKF 알고리즘                 │
├────────────────────────────────────────┤
│                                        │
│  초기화:                               │
│    x̂₀, P₀ 설정                        │
│                                        │
│  매 시각 k:                            │
│                                        │
│  [1] 자코비안 계산                      │
│    F_k = ∂f/∂x |_{x̂_{k-1}}           │
│                                        │
│  [2] 예측 (Prediction)                 │
│    x̂⁻_k = f(x̂_{k-1}, u_k)           │
│    P⁻_k = F_k · P_{k-1} · F_k^T + Q  │
│                                        │
│  [3] 측정 자코비안                      │
│    H_k = ∂h/∂x |_{x̂⁻_k}             │
│                                        │
│  [4] 업데이트 (Update)                 │
│    y_k = z_k - h(x̂⁻_k)              │
│    S_k = H_k · P⁻_k · H_k^T + R      │
│    K_k = P⁻_k · H_k^T · S_k^{-1}     │
│    x̂_k = x̂⁻_k + K_k · y_k          │
│    P_k = (I - K_k · H_k) · P⁻_k      │
│                                        │
└────────────────────────────────────────┘
```

### 5. EKF의 한계

```
한계 1: 강한 비선형
  ┌──────────────────────────┐
  │   접선 근사가 실제와 많이 다름  │
  │                          │
  │    ╱  실제               │
  │  ╱╱╱                     │
  │╱   ╱ 접선               │
  │  ╱                       │
  │╱                         │
  └──────────────────────────┘
  → 비선형이 강하면 선형 근사 부정확
  → 추정 오차 발생, 심하면 발산

한계 2: 큰 불확실성
  P가 클 때 (초기화 직후 등)
  → 선형화 범위를 벗어나는 상태 가능
  → 잘못된 자코비안 → 잘못된 업데이트

한계 3: 회전 표현 문제
  쿼터니언: q = [w, x, y, z], |q| = 1 (제약!)
  → 업데이트 후 |q| ≠ 1 → 정규화 필요
  → Over-parameterization 문제
  → ESKF로 해결 (Week 5)
```

## 💡 꼭 이해해야 할 핵심 개념

### 선형화 오차와 일관성

```
EKF의 근본적 문제:

1. 자코비안을 "추정값"에서 계산
   → 추정값 자체가 틀릴 수 있음
   → 잘못된 점에서 선형화 → 오차 악화

2. 일관성(Consistency) 문제
   → 실제 오차보다 P가 작아질 수 있음
   → "자신감 과잉" → 측정값 무시 → 발산

3. 해결책들
   → ESKF: 작은 오차에서 선형화 (Week 5)
   → UKF: 시그마 포인트 (선형화 불필요)
   → 최적화 기반: Factor Graph (VINS 방식)
```

### 수치적 자코비안 (디버깅 팁)

```cpp
// 해석적 자코비안이 맞는지 수치적으로 검증
Eigen::MatrixXd numericalJacobian(
    std::function<Eigen::VectorXd(Eigen::VectorXd)> f,
    Eigen::VectorXd x, double eps = 1e-7) {

    int n = x.size();
    Eigen::VectorXd f0 = f(x);
    int m = f0.size();
    Eigen::MatrixXd J(m, n);

    for (int i = 0; i < n; i++) {
        Eigen::VectorXd x_plus = x;
        x_plus(i) += eps;
        J.col(i) = (f(x_plus) - f0) / eps;
    }
    return J;
}
// 해석적 J와 수치적 J의 차이가 1e-5 이하면 OK
```

## 🔍 자체 점검 - 이해했는지 확인!

### Q1: EKF가 필요한 이유
**Q:** 일반 칼만 필터 대신 EKF를 쓰는 이유는?

**A:** 실제 시스템(IMU 적분, 카메라 투영, 회전 등)이 비선형이기 때문입니다. 선형 칼만 필터의 F·x를 f(x)로, H·x를 h(x)로 대체하고, 자코비안으로 공분산을 전파합니다.

### Q2: 자코비안의 역할
**Q:** EKF에서 자코비안 F의 역할은?

**A:** 비선형 함수 f(x)를 현재 추정값 근처에서 선형 근사하는 것입니다. 공분산 전파(P⁻ = F·P·Fᵀ + Q)에 사용됩니다. 상태 예측 자체는 비선형 f(x)를 그대로 사용합니다.

### Q3: 선형화 오차
**Q:** EKF에서 선형화 오차가 커지는 상황은?

**A:** (1) 비선형이 매우 강할 때 (급격한 회전 등), (2) 현재 추정값이 실제 값과 멀 때 (잘못된 점에서 선형화), (3) 초기화 직후처럼 P가 매우 클 때. 이런 상황에서 EKF는 부정확하거나 발산할 수 있습니다.

### Q4: EKF vs 최적화
**Q:** VINS-Mono는 EKF 대신 최적화(Factor Graph)를 쓰는 이유는?

**A:** (1) EKF는 선형화 오차가 누적되지만, 최적화는 반복적으로 재선형화 가능, (2) EKF는 마르코프 가정(직전 상태에만 의존)이지만, 최적화는 여러 프레임을 동시에 고려, (3) 최적화가 일반적으로 더 정확. 단, 계산량이 더 큼.

## 🎯 이번 주 핵심 요약

1. **EKF = 비선형 시스템용 칼만 필터**
   - f(x)로 예측, h(x)로 측정
   - 자코비안 F, H로 선형 근사

2. **자코비안 = 비선형 함수의 1차 미분**
   - 현재 추정값에서 매 스텝 재계산
   - 공분산 전파에 사용

3. **EKF 알고리즘은 KF와 구조 동일**
   - 차이: F→자코비안, f(x) 직접 사용
   - 예측 → 업데이트 사이클 동일

4. **EKF의 한계**
   - 강한 비선형에서 부정확
   - 회전 표현 문제 (쿼터니언 정규화)
   - → ESKF, UKF, 최적화로 개선

5. **VIO에서의 위치**
   - MSCKF: EKF 기반 VIO
   - VINS: 최적화 기반 (EKF보다 정확)
   - 둘 다 자코비안 개념은 동일하게 사용
