## 📚 핵심 개념 자세히 알아보기

### 1. IMU 직접 적분 (Dead Reckoning)

```
가장 단순한 IMU 적분:

초기 상태: R(0), v(0), p(0)

매 IMU 데이터 (a_m, ω_m)마다:
  1. 바이어스 제거
     a = a_m - b_a
     ω = ω_m - b_g

  2. 회전 업데이트
     R(t+dt) = R(t) · Exp(ω · dt)

  3. 속도 업데이트 (중력 보상)
     v(t+dt) = v(t) + (R(t) · a + g) · dt

  4. 위치 업데이트
     p(t+dt) = p(t) + v(t) · dt + 0.5 · (R(t) · a + g) · dt²

문제: 노이즈와 바이어스가 적분되어 드리프트 발생!
```

---

### 2. 드리프트의 원인

```
원인 1: 가속도 노이즈 → 속도 드리프트
  a_noise가 매 스텝 적분됨
  → v_drift ∝ σ_a · √t
  → p_drift ∝ σ_a · t^{3/2}
  → 1초 후 약 cm, 10초 후 약 m 단위!

원인 2: 가속도 바이어스 → 이차 함수 드리프트
  b_a가 상수로 계속 적분됨
  → v_drift = b_a · t
  → p_drift = 0.5 · b_a · t²
  → 바이어스 0.01 m/s², 10초 → 0.5m 드리프트!

원인 3: 자이로 바이어스 → 회전 드리프트
  b_g가 적분 → 회전 오차
  → 회전 오차가 가속도 방향을 틀어뜨림
  → 중력 방향 오차 → 속도/위치에 연쇄 영향!
  → 가장 치명적!
```

---

### 3. 중력 보상의 중요성

```
가속도계 출력: a_m ≈ [0, 0, 9.81] (정지 시)

중력을 제거해야 실제 가속도를 얻음:
  a_world = R · (a_m - b_a) + g
           = R · [0, 0, 9.81] + [0, 0, -9.81]
           = [0, 0, 0]  (정지이므로 정확!)

만약 회전 R이 조금이라도 틀리면?
  R에 0.01 rad 오차 → 중력 일부가 수평으로 누출
  → 0.01 × 9.81 ≈ 0.1 m/s² 가짜 가속도
  → 1초 적분 → 0.05 m 오차
  → 10초 적분 → 5 m 오차!

→ 자이로 바이어스에 의한 회전 오차가 가장 치명적
```

### IMU만으로는 왜 안 되는가?

```
실험으로 확인할 것:

결론:
  → IMU 단독 = 몇 초 만에 쓸모없어짐

  → Pre-integration은 이 보정을 효율적으로 하는 방법
```

## 🔍 자체 점검 - 이해했는지 확인!

### Q1: 드리프트 원인
**Q:** IMU 적분에서 가장 치명적인 드리프트 원인은?

**A:** 자이로 바이어스입니다. 회전 오차가 중력 방향을 틀어뜨려 가짜 수평 가속도를 만들고, 이것이 적분되어 위치 오차로 빠르게 확대됩니다.

### Q2: 중력 보상
**Q:** 회전 추정이 0.01 rad 틀리면 1초 후 위치 오차는 약 얼마?

**A:** 약 0.05m입니다. 0.01 rad × 9.81 m/s² ≈ 0.1 m/s² 가짜 가속도, 0.5 × 0.1 × 1² = 0.05m.

### Q3: VIO 동기
**Q:** 이 실험 결과가 VIO 설계에 주는 교훈은?

**A:** Vision으로 주기적으로 보정하지 않으면 IMU 적분이 빠르게 발산합니다. VIO에서 Vision의 역할은 이 드리프트를 교정하는 것입니다.

### Q4: Pre-integration 연결
**Q:** 직접 적분 vs Pre-integration의 차이는?

**A:** 직접 적분은 절대 포즈에서 적분하지만, Pre-integration은 출발 포즈와 무관한 상대 변화량을 계산합니다. 최적화에서 포즈가 바뀌어도 재적분이 불필요합니다.
