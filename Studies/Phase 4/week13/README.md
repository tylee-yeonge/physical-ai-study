## 시작하기 전에 — 본 주의 메시지


본 phase 의 두 블로그는 **함께 읽혔을 때** 가장 강력한 메시지를 만든다:


- RT-2 블로그 = VLA 의 학술적 흐름 이해
- OpenVLA 블로그 = 본인 hardware 에서 직접 검증


이번 주는 두 블로그가 **연결된 한 작품** 으로 보이도록 다듬는 작업.

## 핵심 개념


### 1. 두 블로그의 cross-link 패턴


```markdown
# RT-2 블로그 끝부분에:
"다음 글: [OpenVLA + RTX 4070 실측 - 5Hz 가 양산에서 의미하는 것](link)"


# OpenVLA 블로그 시작부분에:
"이전 글에서 [RT-2 의 학술적 흐름](link)을 정리했습니다.
본 글에서는 RT-2 의 open-source 버전 OpenVLA 를 직접 돌려본 결과를..."
```


이 cross-link 가 두 블로그를 한 시리즈로 묶음.


### 2. 다이어그램 톤 통일


| 통일 항목 | 표준 |
|---|---|
| Mermaid theme | default 또는 darkMode 일관 |
| Node 모양 | rectangle (default) |
| 화살표 | -->, ==> (특별 강조) 구분 |
| 색상 | 강조 노드만 fill |
| 폰트 크기 | 동일 |


### 3. 본문 퇴고 체크리스트


- [ ] 모든 정량 표현에 단위 ("165 ms", "6 Hz")
- [ ] 다른 모델 (RT-1, RT-2, OpenVLA) 비교 표 일관성
- [ ] section 별 분량 균형 (한 section 이 너무 큼?)
- [ ] 본인 차별화 메시지 한 단락 명확
- [ ] 외부 link 모두 동작 확인


### 4. SEO 메타 정비


| 요소 | RT-2 블로그 | OpenVLA 블로그 |
|---|---|---|
| 제목 | "RT-2 정독 노트: VLM 이 어떻게 로봇 행동을 생성하는가" | "OpenVLA 정독 + RTX 4070 실측: 5Hz 가 양산에서 의미하는 것" |
| URL slug | rt2-vla-deep-dive | openvla-rtx4070-latency |
| 태그 | VLA, RT-2, Foundation Model, Robot | VLA, OpenVLA, latency, 양산 |
| 첫 단락 | RT-2 핵심 + emergent capability 한 줄 | latency 165ms + 양산 의미 한 줄 |


### 5. cross-link 의 SEO 가치


서로 link 하는 두 글이 검색에 노출되면:
- 한 글을 읽는 사람이 다른 글도 읽을 확률 ↑
- 두 글의 site DA (domain authority) 가 서로 강화
- "VLA" 키워드 검색에서 두 글이 함께 노출 가능성


### 6. 본 phase 진입 시 본인이 가진 패


- 블로그 2 편 (퇴고 완료)
- OpenVLA HuggingFace inference 실행 가능

## 자체 점검


**Q1. 두 블로그를 한 시리즈로 만드는 가장 효과적인 방법?**
> cross-link (서로 인용) + 톤 통일 (다이어그램 / 표 / 단락 길이) + 동일 author 명.


**Q2. SEO 키워드 우선순위는?**
> 제목 > URL slug > 태그 > 첫 단락 > 본문. 제목에 "VLA / RT-2 / OpenVLA" 같은 핵심 단어가 반드시 들어가야 검색 노출.


**Q3. 퇴고 시 가장 자주 발견되는 결함은?**
> (1) 정량 표현의 단위 누락, (2) section 별 분량 불균형, (3) 외부 link 깨짐.


**Q4. 본인 차별화 메시지의 위치는?**
> Section 7 (양산 SW 엔지니어의 관점). 한 단락 (200~300자) 으로 명확히. 면접관이 가장 자주 인용하는 부분.


**Q5. 두 블로그가 함께 면접관에게 던지는 메시지는?**
> "이 사람은 VLA 의 학술적 흐름 (RT-2 -> OpenVLA) 을 일관되게 이해하고, 본인 hardware 로 직접 검증하며, 양산 SW 관점으로 해석한다."
