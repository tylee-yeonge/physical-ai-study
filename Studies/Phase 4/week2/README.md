### Week 1 복습: IMU 측정 모델

```
a_meas = a_true + g + noise + bias
ω_meas = ω_true + noise + bias
```

Week 1에서 noise와 bias라는 단어를 사용했지만, 정확히 어떤 성질을 가지는지는 다루지 않았습니다. 이번 주에는 이 **노이즈를 수학적으로 모델링**합니다.

### 비유: 저울의 오차

```
좋은 저울 vs 나쁜 저울:

좋은 저울 (낮은 노이즈):
  측정: 100.01, 99.98, 100.02, 100.01 → 평균 ≈ 100.00 ✅

나쁜 저울 (높은 노이즈):
  측정: 102.3, 97.8, 103.1, 96.5    → 평균 ≈ 100.0 (평균은 맞지만 개별값 부정확)

기울어진 저울 (바이어스):
  측정: 101.02, 101.01, 100.98, 101.03 → 평균 ≈ 101.01 (항상 +1 오차!)
  → 이 +1이 "바이어스"!
  → 바이어스를 알면 보정 가능, 모르면 계속 틀림
```

## 📚 핵심 개념 자세히 알아보기

### 1. White Noise (백색 잡음)

**정의:** 매 시각 독립적으로 발생하는 랜덤 노이즈

```
White Noise 특성:
  - 시간적 상관관계 없음 (independent)
  - 가우시안 분포: n ~ N(0, σ²)
  - 모든 주파수 성분이 동일 (→ "백색")

시각화:
  값
   │   *         *
   │ *   *   *     *   *
   ├─────*───*───────*───────→ 시간
   │       *       *
   │         *   *
   │
  평균으로 필터링 가능 (N개 평균 → σ/√N)
```

**가속도계 White Noise:**
```
파라미터: σ_a (= acc_n in VINS)
단위: m/s²/√Hz  (noise density)
일반적 값: 0.001 ~ 0.01 m/s²/√Hz

이산시간에서:
  n_a ~ N(0, σ_a²/dt)  (dt = 샘플링 주기)

적분 시 영향:
  속도 노이즈: σ_v = σ_a * √t    (Random Walk!)
  위치 노이즈: σ_p = σ_a * t^1.5 / √3
```

**자이로스코프 White Noise:**
```
파라미터: σ_g (= gyr_n in VINS)
단위: rad/s/√Hz
일반적 값: 0.0001 ~ 0.001 rad/s/√Hz

적분 시 영향:
  각도 노이즈: σ_θ = σ_g * √t   (Angular Random Walk)
```

### 2. Bias Random Walk

**정의:** 바이어스 자체가 시간에 따라 천천히 변하는 모델

```
Bias의 특성:
  - 상수가 아님! (시간에 따라 조금씩 변함)
  - Random Walk으로 모델링
  - 온도, 전원 상태, 시간에 영향받음

모델:
  b(t+dt) = b(t) + w * √dt
  여기서 w ~ N(0, σ_b²)

시각화:
  bias
   │        ___
   │       /   \      ___
   │  ____/     \____/   \___
   ├──────────────────────────→ 시간
   │
  → 천천히 랜덤하게 변화 (드리프트)
```

**가속도계 Bias Random Walk:**
```
파라미터: σ_ba (= acc_w in VINS)
단위: m/s³/√Hz
일반적 값: 0.0001 ~ 0.001 m/s³/√Hz

바이어스 변화 모델:
  b_a(t+dt) = b_a(t) + σ_ba * √dt * w   (w ~ N(0,I))
```

**자이로스코프 Bias Random Walk:**
```
파라미터: σ_bg (= gyr_w in VINS)
단위: rad/s²/√Hz
일반적 값: 0.00001 ~ 0.0001 rad/s²/√Hz

바이어스 변화 모델:
  b_g(t+dt) = b_g(t) + σ_bg * √dt * w
```

### 3. 전체 IMU 노이즈 모델

```
┌──────────────────────────────────────────────────────┐
│              IMU 노이즈 모델 정리                       │
├──────────────────────────────────────────────────────┤
│                                                      │
│  가속도계:                                            │
│    a_meas = R^T(a - g) + b_a + n_a                  │
│    ḃ_a = w_ba                                       │
│                                                      │
│    n_a ~ N(0, σ_a² · I)     ← White Noise           │
│    w_ba ~ N(0, σ_ba² · I)   ← Bias Random Walk      │
│                                                      │
│  자이로스코프:                                        │
│    ω_meas = ω + b_g + n_g                           │
│    ḃ_g = w_bg                                       │
│                                                      │
│    n_g ~ N(0, σ_g² · I)     ← White Noise           │
│    w_bg ~ N(0, σ_bg² · I)   ← Bias Random Walk      │
│                                                      │
└──────────────────────────────────────────────────────┘
```

### 4. 노이즈 파라미터 비교

| 파라미터 | VINS 이름 | 소비자급 IMU | 산업용 IMU | 항법급 IMU |
|---------|----------|------------|----------|----------|
| σ_a (acc noise) | acc_n | 0.01 | 0.001 | 0.0001 |
| σ_g (gyro noise) | gyr_n | 0.005 | 0.0005 | 0.00005 |
| σ_ba (acc bias) | acc_w | 0.001 | 0.0001 | 0.00001 |
| σ_bg (gyro bias) | gyr_w | 0.0005 | 0.00005 | 0.000005 |

> 💡 가격 차이: 소비자급 ~$10, 산업용 ~$1,000, 항법급 ~$100,000

### 5. Allan Variance (개념)

**Allan Variance란?**
```
목적: IMU 노이즈 파라미터를 실험적으로 측정하는 방법

방법:
1. IMU를 정지 상태로 수 시간 놓아둠
2. 다양한 시간 간격(τ)으로 평균 계산
3. τ에 따른 분산 변화를 log-log 플롯

Allan Variance 그래프:
  log(σ)
    │ \
    │  \              /
    │   \   ___      /
    │    \_/   \___/
    │
    └────────────────→ log(τ)
         ↑        ↑
     White     Bias
     Noise   Random Walk

기울기 해석:
  -1/2: White Noise (σ_a, σ_g)
  +1/2: Bias Random Walk (σ_ba, σ_bg)
```

### 6. VINS Config 파일의 노이즈 파라미터

**EuRoC 데이터셋 예시 (VINS config):**
```yaml
# IMU 노이즈 파라미터
imu_topic: "/imu0"

# White Noise (측정 노이즈)
acc_n: 0.08         # 가속도계 noise density (m/s²/√Hz)
gyr_n: 0.004        # 자이로 noise density (rad/s/√Hz)

# Bias Random Walk
acc_w: 0.00004       # 가속도계 bias random walk (m/s³/√Hz)
gyr_w: 2.0e-6        # 자이로 bias random walk (rad/s²/√Hz)
```

**파라미터가 VIO에 미치는 영향:**
```
acc_n 너무 크게 설정 → 가속도 측정 무시 → Vision에만 의존
acc_n 너무 작게 설정 → 노이즈에 과적합 → 궤적 진동

gyr_n 너무 크게 설정 → 회전 측정 무시 → 방향 추정 불안정
gyr_n 너무 작게 설정 → 자이로 노이즈 무시 → 잘못된 방향 고집

acc_w, gyr_w 중요성:
  → 바이어스를 "얼마나 빠르게 변하는 것으로 모델링할지"
  → 너무 작으면: 바이어스 업데이트 느림 → 보정 지연
  → 너무 크면: 바이어스 추정 불안정 → 발산 위험
```

## 💡 꼭 이해해야 할 핵심 개념

### 바이어스 추정이 VIO의 핵심인 이유

```
왜 바이어스가 중요한가?

1. White Noise는 평균으로 줄일 수 있음
   N개 평균 → σ/√N → 많이 모으면 작아짐 ✅

2. 바이어스는 평균으로 사라지지 않음
   100개 평균해도 바이어스는 그대로!
   → 반드시 추정해서 빼야 함 ❗

3. 바이어스의 적분 영향
   가속도계 바이어스 b_a:
     속도 오차: b_a × t     (시간에 비례)
     위치 오차: 0.5 × b_a × t²  (시간의 제곱에 비례!)

   자이로 바이어스 b_g:
     각도 오차: b_g × t     (시간에 비례)

4. VIO에서의 바이어스 추정
   → 상태 벡터에 바이어스를 포함!

   x = [position, velocity, rotation, b_a, b_g]
                                       ↑    ↑
                                  이것들을 함께 추정!
```

### 노이즈가 적분에 미치는 영향

```
가속도계 노이즈 σ_a 적분 영향:

  가속도 → (적분) → 속도 → (적분) → 위치

  가속도 오차: σ_a                    (일정)
  속도 오차:   σ_a × √(dt × N)       (√시간에 비례, Random Walk)
  위치 오차:   σ_a × (dt × N)^(3/2)  (시간^1.5에 비례!)

자이로 노이즈 σ_g 적분 영향:

  각속도 → (적분) → 각도

  각속도 오차: σ_g
  각도 오차:   σ_g × √(dt × N)       (Angular Random Walk)
```

### 연속시간 vs 이산시간 노이즈

```
센서 데이터시트: 연속시간 (noise density)
  단위: m/s²/√Hz, rad/s/√Hz

코드에서 사용: 이산시간
  n_d = n_c / √dt

예시:
  연속: σ_a = 0.01 m/s²/√Hz
  dt = 0.005s (200Hz)
  이산: σ_a_d = 0.01 / √0.005 = 0.141 m/s²

  → 이산 노이즈가 훨씬 크게 보이지만,
     √dt를 곱해서 적분하면 결과는 같음
```

## 🔍 자체 점검 - 이해했는지 확인!

### Q1: White Noise vs Bias
**Q:** White Noise와 Bias Random Walk의 핵심적인 차이점은?

**A:**
```
White Noise:
  - 매 시각 독립 (시간 상관관계 없음)
  - 평균으로 줄일 수 있음 (σ/√N)
  - 고주파 진동

Bias Random Walk:
  - 시간적 상관관계 있음 (이전 값에 의존)
  - 평균으로 줄일 수 없음
  - 천천히 변하는 드리프트
  → 반드시 명시적으로 추정해야 함!
```

### Q2: 바이어스 추정 시점
**Q:** VIO에서 바이어스를 언제 추정하나요?

**A:**
```
바이어스는 상태 벡터의 일부로 "항상" 추정합니다.

x = [p, v, R, b_a, b_g]  ← 15차원 상태

- 최적화 기반 (VINS): 슬라이딩 윈도우에서 함께 최적화
- 필터 기반 (MSCKF): 칼만 필터 상태에 포함

바이어스는 느리게 변하므로:
  - 짧은 시간: 거의 상수로 가정 가능
  - 긴 시간: Random Walk 모델로 변화 허용
```

### Q3: VINS 파라미터 튜닝
**Q:** VINS config에서 `acc_n`을 실제보다 10배 크게 설정하면?

**A:**
```
acc_n을 크게 설정 → "가속도계를 못 믿겠다"고 선언

결과:
  1. IMU 측정의 가중치가 낮아짐
  2. Vision에 더 많이 의존
  3. 실내 등 Vision이 좋은 환경: 영향 적음
  4. Vision이 나쁜 환경 (어둠, 블러): 성능 급감
  5. 빠른 움직임에서 추적 실패 가능

→ 실제 센서 특성에 맞는 파라미터가 중요!
→ 데이터시트 또는 Allan Variance로 결정
```

### Q4: 노이즈 단위 변환
**Q:** 연속시간 noise density 0.008 m/s^2/sqrt(Hz)를 200Hz에서 이산 표준편차로 변환하면?

**A:**
```
σ_discrete = σ_continuous / √dt
           = 0.008 / √(1/200)
           = 0.008 / √0.005
           = 0.008 / 0.0707
           = 0.113 m/s²

→ 200Hz에서 각 샘플의 노이즈 표준편차는 0.113 m/s²
→ 연속시간보다 ~14배 크지만, 적분 시 결과는 동일
```

## 🎯 이번 주 핵심 요약

1. **IMU 노이즈 = White Noise + Bias Random Walk**
   - White Noise: 독립적, 평균으로 감소 가능
   - Bias Random Walk: 상관성, 추정 필수

2. **4가지 핵심 파라미터**
   - `acc_n` (σ_a): 가속도계 측정 노이즈
   - `gyr_n` (σ_g): 자이로 측정 노이즈
   - `acc_w` (σ_ba): 가속도계 바이어스 변화율
   - `gyr_w` (σ_bg): 자이로 바이어스 변화율

3. **바이어스 추정 = VIO 핵심**
   - 바이어스는 평균으로 제거 불가
   - 적분 시 t²에 비례하여 위치 오차 누적
   - 상태 벡터에 포함하여 함께 추정

4. **Allan Variance**
   - 노이즈 파라미터를 실험적으로 측정하는 방법
   - 기울기로 White Noise vs Bias 구분

5. **파라미터 설정의 중요성**
   - 실제 센서 특성에 맞는 값 사용
   - 잘못된 설정 → VIO 성능 저하/발산
