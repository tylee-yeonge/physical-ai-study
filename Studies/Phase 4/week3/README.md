> 💡 **핵심 질문**: "예측값과 측정값이 다를 때, 둘 중 어느 쪽을 더 믿어야 할까?"

## 🌟 시작하기 전에

### 왜 칼만 필터를 배우나요?

VIO(Visual-Inertial Odometry)는 결국 **두 센서의 정보를 합치는 것**입니다:

```
IMU:    "나는 1.02m 이동했어" (빠르지만 drift 있음)
Vision: "나는 0.98m 이동했어" (느리지만 안정적)

최적 답: 둘을 적절히 합치면 → 1.00m (두 센서보다 정확!)
```

칼만 필터는 이런 **센서 융합의 기본 도구**입니다.

### 쉬운 비유: 두 친구의 추정

```
상황: 방의 온도를 모름

친구 A (모델/예측): "어제 22°C였고 히터 켰으니까 24°C일 거야"
  → 확신도: 보통 (σ² = 4)

친구 B (측정): "온도계로 재봤는데 23°C야"
  → 확신도: 높음 (σ² = 1)

최적 답: 둘을 확신도에 따라 가중 평균
  = (24×1 + 23×4) / (1+4) = 116/5 = 23.2°C
  → 더 확신하는 친구 B의 값에 가까움!
```

이것이 바로 칼만 필터의 핵심입니다.

## 📚 핵심 개념 자세히 알아보기

### 1. 칼만 필터의 두 단계

```
┌─────────────────────────────────────────────┐
│              칼만 필터 사이클                  │
│                                             │
│  ┌──────────┐         ┌──────────┐          │
│  │  예측     │ ──────→ │  업데이트  │          │
│  │(Predict) │         │(Update)  │          │
│  └──────────┘         └──────────┘          │
│       ↑                      │              │
│       └──────────────────────┘              │
│              매 시각 반복                     │
└─────────────────────────────────────────────┘
```

#### 예측 (Prediction) - "다음에 뭐가 될까?"

```
모델(물리 법칙)을 이용해 다음 상태를 예측

예시: 등속 운동 모델
  위치_예측 = 위치_현재 + 속도 × dt
  속도_예측 = 속도_현재

수학적으로:
  x̂⁻ = F · x̂     ← 상태 예측
  P⁻  = F·P·Fᵀ + Q  ← 공분산(불확실성) 예측

  F: 상태 전이 행렬 (모델)
  Q: 프로세스 노이즈 (모델의 불확실성)
```

**핵심**: 예측만으로는 불확실성(P)이 계속 커짐!

#### 업데이트 (Update) - "측정값으로 보정"

```
측정값이 들어오면 예측을 수정

수학적으로:
  K = P⁻·Hᵀ·(H·P⁻·Hᵀ + R)⁻¹  ← 칼만 게인
  x̂ = x̂⁻ + K·(z - H·x̂⁻)      ← 상태 업데이트
  P = (I - K·H)·P⁻             ← 공분산 업데이트

  H: 측정 행렬 (상태 → 측정 매핑)
  R: 측정 노이즈
  z: 실제 측정값
  K: 칼만 게인 (핵심!)
```

**핵심**: 업데이트 후 불확실성(P)이 줄어듦!

---

### 2. 칼만 게인 - 핵심 중의 핵심

```
K = P⁻ · Hᵀ · (H·P⁻·Hᵀ + R)⁻¹

단순화 (1D, H=1):
K = P⁻ / (P⁻ + R)

해석:
  P⁻ 크고 R 작으면 → K ≈ 1 → 측정값 믿기
  P⁻ 작고 R 크면   → K ≈ 0 → 예측값 믿기

직관:
  "내 예측이 불확실하면(P⁻ 큼) → 측정값을 더 믿자"
  "측정이 불확실하면(R 큼)   → 내 예측을 더 믿자"
```

#### 칼만 게인 시각화

```
K = 0.0                    K = 0.5                    K = 1.0
예측만 100% 믿음          반반 믿음              측정만 100% 믿음

  예측: ●                   예측: ●                   예측: ●
  결과: ●                   결과:        ●            결과:             ●
  측정:             ○       측정:             ○       측정:             ○

  (측정 노이즈 매우 큼)    (둘 다 비슷한 신뢰도)    (예측 노이즈 매우 큼)
```

---

### 3. 칼만 필터 = 가중 평균

1D에서 칼만 필터의 본질을 보면:

```
두 정보의 가중 평균:

  예측: x̂⁻ ± σ_pred     (예측값과 불확실성)
  측정: z  ± σ_meas     (측정값과 불확실성)

  최적 결합:
  x̂ = σ_meas²/(σ_pred² + σ_meas²) · x̂⁻ + σ_pred²/(σ_pred² + σ_meas²) · z

  결과의 불확실성:
  1/σ_result² = 1/σ_pred² + 1/σ_meas²

→ 결과는 항상 두 입력보다 불확실성이 작음!
→ 정보를 합치면 더 정확해짐!
```

#### 숫자 예제

```
예측: 위치 = 10.0m, 불확실성 σ² = 4.0
측정: 위치 = 12.0m, 불확실성 σ² = 1.0

칼만 게인: K = 4.0 / (4.0 + 1.0) = 0.8

업데이트:
  x̂ = 10.0 + 0.8 × (12.0 - 10.0) = 11.6m
  P = (1 - 0.8) × 4.0 = 0.8

결과: 11.6m ± 0.89m
→ 측정(12.0m)에 가까움 (더 확실하니까)
→ 불확실성(0.89) < 두 입력(2.0, 1.0) 어느 것보다 작음!
```

### 4. 공분산의 의미

```
공분산 P = 추정의 불확실성

P 작음 → "내 추정에 자신 있음"
  ├── 칼만 게인 K 작음
  └── 측정값의 영향 적음

P 큼 → "내 추정이 불확실함"
  ├── 칼만 게인 K 큼
  └── 측정값을 더 많이 반영

시간에 따른 P의 변화:
  예측 단계: P 증가 (불확실성 커짐)
  업데이트 단계: P 감소 (측정으로 보정)

  P
  │   /\    /\    /\
  │  /  \  /  \  /  \
  │ /    \/    \/    \
  └──────────────────→ 시간
     ↑     ↑     ↑
   예측  업데이트  예측
```

### 5. VIO에서의 칼만 필터 역할

```
VIO에서의 예측-업데이트:

예측 (IMU):
  - 가속도, 각속도로 다음 포즈 예측
  - 200Hz로 빠르게 예측
  - 단점: drift 누적 → P 계속 증가

업데이트 (Vision):
  - 카메라 이미지로 포즈 보정
  - 20-30Hz로 느리게 업데이트
  - 장점: drift 보정 → P 감소

┌─────────────────────────────────────┐
│  IMU: ████████████████████████████  │ (200Hz)
│  Vision:     ■         ■         ■  │ (20Hz)
│                                     │
│  P:  /\/\/\/↘  /\/\/\/↘  /\/\/\/↘  │
│      예측 반복  업데이트   예측 반복  │
└─────────────────────────────────────┘
```

## 💡 꼭 이해해야 할 핵심 개념

### 칼만 필터의 가정

```
1. 선형 시스템: x_k = F·x_{k-1} + w
   → 실제 VIO는 비선형 → EKF 필요 (Week 4)

2. 가우시안 노이즈: w ~ N(0, Q), v ~ N(0, R)
   → 가우시안이면 평균+공분산으로 완전히 표현 가능

3. 마르코프 성질: 현재 상태는 직전 상태에만 의존
   → x_k는 x_{k-1}만으로 결정 (과거 전체 불필요)
```

### 칼만 필터의 최적성

```
칼만 필터는 선형 가우시안 시스템에서 최적!

"최적"의 의미:
  - 추정 오차의 평균이 0 (unbiased)
  - 추정 오차의 분산이 최소 (minimum variance)
  - 어떤 다른 선형 추정기도 더 나을 수 없음

→ 그래서 50년 넘게 쓰이는 알고리즘!
→ 아폴로 11호 달 착륙에도 사용
```

## 🔍 자체 점검 - 이해했는지 확인!

### Q1: 칼만 게인
**Q:** 칼만 게인 K = 0.9라면, 이것이 의미하는 바는?

**A:** 예측보다 측정을 90% 가까이 믿겠다는 의미입니다. 예측의 불확실성(P)이 측정 노이즈(R)보다 훨씬 크다는 뜻이죠.

### Q2: 공분산 변화
**Q:** 예측만 반복하고 업데이트를 안 하면 공분산 P는 어떻게 되나요?

**A:** P가 계속 커집니다 (P⁻ = F·P·Fᵀ + Q). 프로세스 노이즈 Q가 매번 더해지니까요. 이것이 "IMU만 쓰면 drift" 하는 이유입니다.

### Q3: 가중 평균
**Q:** 예측값 10, 측정값 14, 둘 다 불확실성이 같다면 (P=R) 결과는?

**A:** 정확히 중간인 12입니다. K = P/(P+R) = 0.5이므로 x̂ = 10 + 0.5×(14-10) = 12. 불확실성이 같으면 동일한 가중치를 줍니다.

### Q4: VIO에서의 역할
**Q:** VIO에서 IMU가 예측, Vision이 업데이트라면, 카메라가 가려졌을 때 어떻게 되나요?

**A:** 업데이트 없이 예측만 반복됩니다. P가 계속 커지면서 IMU drift가 누적됩니다. 카메라가 다시 보이면 업데이트로 대폭 보정됩니다. 이 때 K가 매우 커져서 Vision을 거의 100% 믿게 됩니다.

## 🎯 이번 주 핵심 요약

1. **칼만 필터 = 예측 + 업데이트**
   - 예측: 모델로 다음 상태 추정 (불확실성 증가)
   - 업데이트: 측정값으로 보정 (불확실성 감소)

2. **칼만 게인 = "누구를 더 믿을까?"**
   - K → 1: 측정 신뢰
   - K → 0: 예측 신뢰

3. **칼만 필터 = 최적 가중 평균**
   - 두 정보를 불확실성에 따라 합침
   - 결과는 항상 두 입력보다 정확

4. **공분산 P = 불확실성의 척도**
   - 예측 시 증가, 업데이트 시 감소
   - IMU만 → P 발산, Vision 보정 → P 감소

5. **VIO에서의 역할**
   - IMU: 빠른 예측 (200Hz)
   - Vision: 느리지만 안정적 업데이트 (20Hz)
